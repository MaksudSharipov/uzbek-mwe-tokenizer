# Installation

## Install from PyPI

Install the latest stable release of **uzbek-mwe-tokenizer** from PyPI:

```bash
pip install uzbek-mwe-tokenizer
```

## Requirements

- Python >= 3.8
- `torch >= 1.9.0`
- `transformers >= 4.20.0`
- `UzTransliterator >= 0.0.18`
- `sentencepiece >= 0.1.96`

## Install from GitHub Source

```bash
git clone https://github.com/MaksudSharipov/uzbek-mwe-tokenizer.git
cd uzbek-mwe-tokenizer
pip install -r requirements.txt
pip install -e .
```
